## CPOBRAS 0.1.1 — Linux

Versión inicial de prueba distribuida como AppImage para Linux x86-64.
Compatible con Linux Mint 21/22 y Ubuntu 22.04/24.04; construida sobre Ubuntu 22.04.

### Cómo abrirlo

1. Descargá el archivo `.AppImage` de esta página.
2. Hacé clic derecho → **Propiedades → Permisos → Permitir ejecutar como programa**.
3. Abrilo con doble clic. No necesitás instalar Node, Rust ni descargar el código.

Si el sistema no permite ejecutarlo por falta de FUSE, podés usar:

```bash
chmod +x CPOBRAS_0.1.1_amd64.AppImage
./CPOBRAS_0.1.1_amd64.AppImage --appimage-extract-and-run
```

El archivo `SHA256SUMS` permite comprobar que la descarga esté completa.

### Incluye

- Presupuestos, composiciones, cómputos, determinación de precio y planificación.
- Clientes y proveedores con una identidad compartida y vistas separadas.
- Organizaciones, logotipo y documentos para cliente, uso interno e incidencias.
- Respaldos manuales y automáticos en carpeta configurable, con selector del sistema.
- Vinculación P2P de obras para observadores de solo lectura, con invitaciones,
  revocación y conservación de la última copia sin conexión.

Los datos se guardan en la cuenta local del usuario y no dentro del AppImage.
Podés copiar el mismo AppImage a otro equipo: empezará con sus propios datos y
podrá vincular una obra mediante una invitación P2P. Ambos equipos deben estar
abiertos y conectados para recibir una versión nueva.

P2P se verificó mediante conexión directa y relay local real. La conexión a
través del relay público entre dos redes distintas queda pendiente de prueba,
porque el entorno de desarrollo bloquea ese servicio.

Esta versión no tiene firma de distribución ni actualización automática. Antes
de actualizar una instalación con datos importantes, creá una copia de seguridad.
