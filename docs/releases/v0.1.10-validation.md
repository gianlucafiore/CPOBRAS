borrador ante errores, cambio de presupuesto y conflictos de revisión. También
se verifican el rendimiento diario con rollback, la eliminación confirmada de
rubros, los conceptos iniciales de presupuestos nuevos, el plazo de los gastos
y el registro de auditoría de gastos indirectos por organización.

La ejecución inicial detectó fixtures de interfaz anteriores a los cambios de
formularios, cálculos simulados que no contemplaban las nuevas consultas,
pruebas de calendario dependientes de la fecha actual y una revisión de precio
fijada en cero en la prueba IPC. Se actualizaron los contratos de prueba y se
mantuvieron las verificaciones de concurrencia, exportación y navegación. El
servicio de presentación admite los temporizadores del entorno global cuando
el objeto de ventana no los proporciona.

Comandos reproducibles:

```bash
cargo fmt --all -- --check
cargo test --workspace --locked
cargo test --manifest-path tools/backup-check/Cargo.toml --locked
cargo fmt --manifest-path apps/desktop/src-tauri/Cargo.toml -- --check
cargo test --manifest-path apps/desktop/src-tauri/Cargo.toml --locked
npm --prefix apps/desktop ci
npm --prefix apps/desktop test
npm --prefix apps/desktop run build
npm --prefix apps/desktop run test:browser
```

La ejecución nativa necesita las dependencias Tauri del sistema; GitHub Actions
las instala antes de ejecutar la suite. La release compila en ejecutores de cada
sistema, comprueba el arranque de cada paquete y verifica los SHA-256 antes de
publicar Linux x86-64, Windows x86-64 y macOS Apple Silicon e Intel.
