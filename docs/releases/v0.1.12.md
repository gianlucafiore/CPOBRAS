# CPOBRAS 0.1.12

- Los conceptos de Determinación de precio pueden mostrarse separados en la cotización del cliente, por ejemplo honorarios y aportes. El check está desmarcado por defecto; su explicación aparece al pasar el mouse por la fila o enfocarlo con el teclado.
- Vista previa, PDF y Excel muestran los conceptos elegidos respetando su posición respecto de los impuestos. Se retiran del importe distribuido entre las partidas para evitar sumarlos dos veces; el cálculo y el total del presupuesto se conservan.
- Opciones explica cómo abrir una base recibida y cómo crear una base vacía. Los errores distinguen ambas operaciones y se conserva la protección contra sobrescribir archivos existentes.
- El aviso de base incompatible indica el formato de la base, el máximo admitido por la aplicación y la necesidad de actualizar los demás equipos.

## Bases de datos compartidas entre equipos

Esta versión admite el esquema SQLite 41 y el formato de intercambio JSON 11. Puede abrir las bases de versiones anteriores y actualizarlas automáticamente. También abre las bases de esquema 41 creadas con la rama de desarrollo de estos cambios.

Guardá una copia de seguridad antes de actualizar. Las versiones 0.1.11 y anteriores no pueden abrir una base actualizada al esquema 41; actualizá también los otros equipos a 0.1.12. El formato es el mismo en Windows, Linux y macOS.

Para usar una base que te pasaron, guardá una copia en una carpeta local con permiso de escritura (por ejemplo, Documentos) y elegí **Inicio → Opciones → Abrir base de datos…**. No hace falta reemplazar la base de AppData ni usar **Nueva base de datos…**. Si copiás el archivo SQLite directamente, cerrá primero la aplicación de origen; también podés generar una copia desde la aplicación.

## Descargas portables

- **Linux x86-64:** `.AppImage`; darle permiso de ejecución y abrirlo. Sin FUSE, usar `--appimage-extract-and-run`.
- **Windows x86-64:** `_windows_x86_64_portable.exe`; requiere Windows 10/11 con Microsoft Edge WebView2 Runtime.
- **macOS Apple Silicon:** `_macos_aarch64_portable.zip`.
- **macOS Intel:** `_macos_x86_64_portable.zip`.

En macOS, descomprimir y abrir `CPOBRAS.app`. Las aplicaciones no tienen firma comercial ni notarización de Apple; puede ser necesario autorizar su apertura en Privacidad y seguridad.

En esta publicación se compilan los paquetes y se verifican los archivos generados y sus sumas `SHA256SUMS`. No se ejecutan nuevas suites ni comprobaciones de arranque.
