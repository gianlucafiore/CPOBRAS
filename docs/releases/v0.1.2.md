# CPOBRAS 0.1.2

- Identidad visual del yacaré en la cabecera, ventana e iconos del paquete.
- Obras externas en Inicio, con organización de origen, propietario y fecha de copia.
- Consulta de obras externas desde las pestañas habituales, con estado «Solo lectura».
- Permisos por observador para presupuesto, determinación de precio, insumos,
  gestión, contabilidad, planificación y datos de obra. Los datos se filtran antes de enviarse.
- Identidades estables de las filas de precio heredadas para evitar transferencias P2P sin cambios.

Ambos equipos deben actualizarse para aprovechar las nuevas vistas y permisos.
Los permisos nuevos no eliminan copias o documentos que ya se hayan descargado.

En Linux, descargar el archivo `.AppImage`, darle permiso de ejecución desde
Propiedades → Permisos y abrirlo. Si FUSE no está disponible, ejecutar:

```bash
chmod +x CPOBRAS_0.1.2_amd64.AppImage
./CPOBRAS_0.1.2_amd64.AppImage --appimage-extract-and-run
```
