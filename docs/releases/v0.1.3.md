# CPOBRAS 0.1.3

## Cambios

- Cantidad acumulada y porcentaje sincronizados en las certificaciones. Se muestran como máximo dos decimales, truncados, conservando la precisión interna para calcular y guardar.
- El certificado PDF del subcontratista omite el bloque de ajuste contractual cuando no hay un ajuste pactado.
- El popup de certificados del subcontrato tiene márgenes internos, mayor ancho y una tabla desplazable; sus botones permanecen accesibles.
- Pedidos y entregas distinguen lo recibido, lo solicitado por recibir y lo disponible para solicitar. Una entrega directa reduce el cupo posterior.
- Los pedidos con movimientos se consultan mediante «Ver pedido» y el editor del Gantt se abre con doble clic.

## Descargas

- **Linux x86-64:** descargar el `.AppImage`, darle permiso de ejecución y abrirlo. En sistemas sin FUSE, ejecutarlo con `--appimage-extract-and-run`.
- **Windows x86-64:** descargar `CPOBRAS_0.1.3_windows_x86_64_portable.exe` y abrirlo; no requiere instalar CPOBRAS. Requiere Windows 10/11 y Microsoft Edge WebView2 Runtime (habitualmente ya instalado). Si falta, instalar el runtime oficial de Microsoft.

Los datos se guardan en el perfil del usuario, fuera del ejecutable, en ambos sistemas. El programa no traslada la base al copiar el archivo. Antes de actualizar, se recomienda conservar una copia de seguridad desde la aplicación.

Los archivos `SHA256SUMS` permiten verificar la integridad de ambas descargas. Los ejecutables no llevan firma de un certificado comercial de editor.
