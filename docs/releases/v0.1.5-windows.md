# CPOBRAS 0.1.5 — Windows portable

Corrige la restauración de copias de seguridad en Windows:

- La confirmación se muestra dentro de CPOBRAS, con el nombre de la copia y acciones explícitas para restaurar o cancelar.
- La copia preventiva abre el archivo con permiso de escritura antes de sincronizarlo, como requiere Windows.
- Los errores de restauración permanecen visibles y permiten volver a intentar.

El gestor nativo de respaldos pasa pruebas de creación, traslado y restauración en Windows y Linux. La clave de IA se guarda en el almacén de credenciales del sistema operativo, fuera de la base SQLite y de sus copias; debe configurarse en cada equipo.

Descargar `CPOBRAS_0.1.5_windows_x86_64_portable.exe`. Requiere Windows 10/11 con Microsoft Edge WebView2 Runtime. Verificar el archivo con `SHA256SUMS`.

Conservar el respaldo original antes de restaurar. El programa guarda automáticamente una copia preventiva del estado actual.

Esta actualización publica únicamente el portable de Windows. Los portables de Linux y macOS continúan disponibles en el release v0.1.4.
