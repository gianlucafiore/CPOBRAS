# CPOBRAS 0.1.6 — Windows portable

## Apertura de bases

- Los errores de «Archivo → Abrir base de datos» se muestran dentro de la aplicación, con la ruta seleccionada, y permiten reintentar.
- Se informa si el selector devuelve una cancelación o si el archivo elegido ya está activo.
- Las pruebas nativas de creación, selección, reapertura y manejo de errores se ejecutan en Windows y Linux.

Esta versión mejora la visibilidad del fallo reportado al abrir una base local. No se ha confirmado aún su causa en la VM del usuario.

Incluye las correcciones de respaldos de 0.1.5. Descargar `CPOBRAS_0.1.6_windows_x86_64_portable.exe`; requiere Windows 10/11 y Microsoft Edge WebView2 Runtime. Se incluye `SHA256SUMS`.

La clave de IA permanece en el almacén de credenciales del usuario del sistema, fuera de SQLite y de sus copias.
