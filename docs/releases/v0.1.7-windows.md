# CPOBRAS 0.1.7 — Windows portable

Corrige el rechazo de bases de Linux con «La estructura del archivo no coincide con una base de CPOBRAS».

SQLite conserva los saltos de línea de las migraciones SQL. Los checkouts de Windows podían incorporar CRLF, mientras que Linux usaba LF; la comparación literal rechazaba estructuras equivalentes. Ahora se normaliza CRLF a LF al validar, y los archivos SQL del repositorio se fijan en LF para futuras compilaciones.

La validación de estructura e integridad se conserva: las bases con tablas o columnas diferentes continúan rechazándose. Incluye errores visibles al abrir una base y las correcciones de respaldos de 0.1.5.

Descargar `CPOBRAS_0.1.7_windows_x86_64_portable.exe`; requiere Windows 10/11 y Microsoft Edge WebView2 Runtime. Se incluye `SHA256SUMS`.

Para abrir un respaldo existente: conservar el original, hacer una copia local y seleccionarla desde Archivo → Abrir base de datos. No es necesario cambiar su nombre.
